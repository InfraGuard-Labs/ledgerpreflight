# Security policy

Report suspected vulnerabilities privately to the repository owner's security contact or private vulnerability-reporting channel before publishing exploit details. Do not send production secrets or proprietary artifacts. Arrange a private disclosure channel with the maintainers before sharing sensitive details.

Version 0.1.0 is intended for external evaluation of static preflight and existing-TVU analysis. See docs/SECURITY-MODEL.md for trust boundaries and limits. Dependency scan results and limitations are recorded with release validation; a successful test run is not proof of absence of vulnerabilities.
